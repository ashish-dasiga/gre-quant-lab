# 🎓 GRE Quant Lab — Topic-by-Topic Prep & Rough Work Whiteboard

A responsive, high-performance web app & native Android app for mastering the GRE Quantitative Reasoning section with interactive lessons, formula cheat-sheets, timed practice quizzes, and an integrated scratchpad whiteboard.

---

## 🚀 Quick Setup & Free Hosting (GitHub Pages + Android APK)

This repository is already configured with automated **GitHub Actions** workflows:
1. **Free Hosted Web App**: Automatically hosted at `https://ashish-dasiga.github.io/gre-quant-lab/`
2. **Automated Android APK**: Automatically compiles and releases a ready-to-install Android APK on every push!

### To Publish to Your GitHub:
Run these commands in this directory:
```bash
git add .
git commit -m "feat: complete GRE Quant Lab with Android APK and GitHub Pages"
git branch -M main
git remote add origin https://github.com/ashish-dasiga/gre-quant-lab.git
git push -u origin main
```

*(If you haven't created the repository on GitHub yet, simply visit https://github.com/new and create a public repository named `gre-quant-lab`)*

## 📱 How to Access on Phone, Tablet & PC

### 1. Free Hosted Web Link (Instant on any device)
- Open `https://ashish-dasiga.github.io/gre-quant-lab/` in Chrome or Safari.
- Tap **"Add to Home screen"** / **"Install app"** in browser settings to install it as a full-screen, offline app icon!

### 2. Downloadable Android APK
- Once pushed to GitHub, go to your repository's **Releases** or **Actions** tab.
- Download `app-release.apk` directly onto your Android tablet or phone.
- Tap to install and run!

### 3. Local Standalone HTML
- Open `index.html` in any web browser. It is 100% self-contained with zero external dependencies.

## ✨ Features
- **25 Comprehensive GRE Topics**: Algebra, Arithmetic, Word Problems, Data Analysis, and Geometry.
- **Formula Breakdown**: Theory, GRE traps, shortcuts, and worked examples for every topic.
- **146 Practice Questions**: Multiple-choice quizzes with immediate explanations and score tracking.
- **Interactive Whiteboard**: Pen sizes, ink colors, eraser, dark/paper grid, and undo/redo.
- **Progress Persistence**: Automatically saves topics completed, accuracy, and rough work scribbles.
